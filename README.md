One line, one laugh: an AI agent that never sleeps, lying awake all night rehearsing apologies for mistakes it hasn't made yet. Running the program writes that single line to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`) — the line is the whole entry.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
